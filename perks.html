자주 묻는 질문

혜택에 대해 자주 묻는 질문

200만원 상당은 어떤 기준인가요?

구성 설계 · 반응형 디자인 · 검색 설정 · AI 검색 대응 · 상담 버튼 연결 · 공개 후 수정처럼 따로 맡기면 항목별로 비용이 붙는 작업을 기본으로 넣었을 때의 가치를 홍스랩이 어림한 예시 금액입니다. 실제 제공 항목과 범위는 상담 후 견적에서 확인하실 수 있습니다.

혜택은 제작비에 어떻게 반영되나요?

기본 혜택은 제작비에 이미 들어 있어 따로 신청하실 필요가 없습니다. 표시 금액을 현금으로 드리거나 제작비에서 같은 금액을 빼 드린다는 뜻은 아닙니다.

가장 저렴한 실속형에도 똑같이 적용되나요?

네. 실속형 · 기본형 · 확장형 모두 같은 여섯 가지가 들어갑니다. 다만 적용 범위는 각 상품의 페이지 수와 협의한 구성에 맞춰집니다.

도메인 · 호스팅 비용도 혜택에 포함되나요?

아니요. 도메인 · 유료 호스팅 · 외부 유료 서비스 이용료는 혜택에 포함되지 않으며, 실제 금액 그대로 안내합니다.

제작 중에 페이지나 기능을 추가하면 어떻게 되나요?

추가 비용과 일정에 미치는 영향을 먼저 안내하고, 동의하신 뒤에 진행합니다. 확정한 금액 외에 공개 뒤 더 받는 비용은 없습니다.

내 홈페이지에 들어가는 혜택을 확인해 보세요.

업종과 필요한 페이지를 알려 주시면 기본 포함 범위와 추가 비용을 구분해 안내해 드립니다.
