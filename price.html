애매한 부분은 결제 전에 먼저 물어봐 주세요. 작업 범위를 같이 정리한 뒤 금액을 확정합니다.

추가 견적비용이 더 생길 수 있는 경우

  • 페이지 추가상품 기준 페이지 수를 넘길 때 페이지당 추가 견적
  • 기능 추가예약 · 결제 · 회원가입 · 게시판 · 관리자 화면 · 외부 API 연동 등 기능 범위에 따라 별도 견적
  • 전체 디자인 변경확정한 시안을 처음부터 다시 그리는 경우
  • 외부 실비도메인(연 단위) · 유료 호스팅 · 외부 유료 서비스 이용료는 실제 금액 그대로
  • 웹앱 · 플랫폼기능 범위를 들은 뒤 상담에서 별도 견적

모든 추가 비용은 작업 시작 전에 금액을 먼저 안내하고 동의를 받은 뒤 진행합니다.

추가 없음더 받지 않는 것

  • 배포 후 1개월 수정합의한 구성 안에서의 문구 · 사진 · 배치 수정은 횟수 제한 없이 무료
  • 기본 포함 12가지반응형 · 검색 설정 · 공유 미리보기 · 전화 · 지도 연결 등은 옵션이 아닙니다
  • 상담 · 견적상담, 구성 제안, 견적 산출은 무료
  • 공개 후 추가 청구제작 전에 확정한 금액 외에 공개 뒤에 더 받는 비용이 없습니다

자료가 완벽하지 않아도 괜찮습니다. 네이버 플레이스 · 블로그 · SNS 자료를 바탕으로 필요한 문구를 함께 정리해 드립니다.

업종과 필요한 페이지만 알려주세요.
